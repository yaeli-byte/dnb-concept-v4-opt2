# D&B — Concept Iteration V4 (Opt 2)

RTL Hebrew desktop homepage concept for Dun & Bradstreet, built 1:1 from the Figma
frame **"D&B concept iteration V4 → Opt 2"**. Single-file vanilla HTML/CSS.

- Fixed 1440px desktop layout, RTL, font **Heebo** (+ **Darker Grotesque** for stat numbers).
- Sections: header · flowing-wave hero · stats · solutions bento.
- Complex graphics (wave, gradient cards, logo, headline) are exported from Figma;
  text, layout, and the interactive CTA (with hover state) are real HTML/CSS.

## Run locally
```bash
python3 -m http.server 4452
# open http://localhost:4452
```
